\begin{frame}{LeNet-5}
    \begin{figure}
        \centering
        \includegraphics[width=0.8\textwidth,height=0.38\textheight,keepaspectratio]{images/cnn/lenet5.png}
        \caption*{\scriptsize LeNet-5 architecture. Adapted from LeCun et al., 1998.}
    \end{figure}
    {\small
        \begin{itemize}
            \item LeNet-5 is a pioneering convolutional neural network (CNN) architecture developed by Yann LeCun and his collaborators; the LeNet series began in 1989 and culminated in LeNet-5 (LeCun et al., 1998).
            \item It was built to recognize handwritten digits, like those in the MNIST dataset.
            \item The network uses layers that look for patterns (convolution), shrink images (pooling), and finally make decisions (fully connected layers).
            \item LeNet-5 introduced ideas like using filters to find features and pooling to reduce size, which are now common in modern CNNs.
        \end{itemize}
    }
\end{frame}

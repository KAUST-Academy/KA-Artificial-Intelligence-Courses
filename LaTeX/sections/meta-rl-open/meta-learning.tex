\section{Meta-Learning}

% ---------------------------------------------------------------- Slide 8
\begin{frame}{What is meta-learning?}
\begin{columns}[c]
\begin{column}{0.62\textwidth}
\begin{itemize}\itemsep0.4em
    \item \textbf{Meta-learning $=$ learning to learn:} use \emph{many} training tasks to
          learn a \emph{learning procedure} that adapts to a \emph{new} task fast.
    \item Having already solved 100 tasks isn't a burden --- it's the \empr{signal} we
          learn from. (Closely related to multi-task learning.)
    \item \textbf{What could ``the learner'' be?} Three recipes for the same goal:
    \begin{itemize}
        \item a \textbf{learned optimizer} --- replace hand-tuned SGD with a \emph{learned}
              update rule (the figure);
        \item a \textbf{sequence model (RNN)} that reads past experience and adapts with
              \emph{no extra gradient steps} --- \empr{the route we follow today};
        \item a \textbf{representation} that a few fine-tuning steps adapt to any task
              (e.g.\ MAML).
    \end{itemize}
\end{itemize}
\end{column}
\begin{column}{0.38\textwidth}
\centering
\includegraphics[width=\linewidth]{images/meta-rl-open/figures/meta-learn-bird.jpg}\\[0.3em]
{\scriptsize A \emph{learned optimizer}: having seen many loss landscapes, it recognises
``I've seen this before'' and navigates a new one better than plain gradient descent.}
\end{column}
\end{columns}
\end{frame}

% ---------------------------------------------------------------- Slide 9
\begin{frame}{Why is meta-learning a good idea?}
\begin{itemize}
    \item Deep reinforcement learning, especially model-free, requires a huge number of
          samples
    \item If we can meta-learn a faster reinforcement learner, we can learn new tasks
          efficiently!
    \item What can a meta-learned learner do differently?
    \begin{itemize}
        \item Explore more intelligently
        \item Avoid trying actions that are know to be useless
        \item Acquire the right features more quickly
    \end{itemize}
\end{itemize}
\end{frame}

% ---------------------------------------------------------------- Slide 10 (step 1: the setup)
\begin{frame}{Warm-up: ``learning to learn'' in supervised learning}
\begin{columns}[c]
\begin{column}{0.5\textwidth}
\footnotesize
The cleanest place to see the idea --- \textbf{few-shot image classification}:
\begin{itemize}\itemsep3pt
   \item you are shown a handful of labelled images of classes you have \emph{never seen}
         --- the \empr{support set} (a tiny training set $\mathcal{D}^{\text{tr}}$);
   \item then you must label a \emph{new} image --- the \empr{query} $x$.
\end{itemize}
\vspace{0.4em}
Ordinary learning trains \emph{once} on one big dataset. Here each \textbf{task} gives only
a \emph{few} examples --- but there are \textbf{many} tasks to learn the \emph{trick} from.
\end{column}

% ---------------------------------------------------------------- Slide 11 (step 2: the mechanism)
\begin{frame}{How? A sequence model reads the support set}
\begin{columns}[c]
\begin{column}{0.45\textwidth}
\footnotesize
One network, three steps:
\begin{enumerate}\itemsep4pt
   \item feed the labelled examples $(x_1,y_1),(x_2,y_2),\dots$ into an \textbf{RNN}, one at
         a time;
   \item its \textbf{hidden state} $h$ builds a \emph{summary} of the support set --- what
         each class looks like;
   \item feed the \textbf{query} $x$; conditioned on $h$, the RNN outputs the label $y$.
\end{enumerate}
\vspace{0.5em}
\textbf{Why an RNN?} it can swallow \emph{any number} of examples and condition its answer
on all of them --- \empr{no separate training run, no gradient steps at test time}.
\end{column}
\begin{column}{0.55\textwidth}
\centering
\resizebox{\linewidth}{!}{%

% ---------------------------------------------------------------- Slide 12 (step 3: what's learned)
\begin{frame}{What is actually learned? Two kinds of parameters}
The network carries \textbf{two} kinds of parameters:
\vspace{0.4em}
\begin{itemize}\itemsep0.7em
   \item \empr{meta-weights} $\theta$ --- the RNN's weights, \textbf{shared across all
         tasks} and \emph{trained} so the RNN behaves like a good learning algorithm.
         \emph{Slow}, learned once (over thousands of tasks).
   \item \empr{hidden state} $h_i$ --- formed \textbf{per task} by reading that task's
         support set. \emph{Fast}, no gradient, different every task.
\end{itemize}
\vfill
\begin{center}
{\large $\phi_i = [\,\underbrace{h_i}_{\text{fast, per-task}},\ \underbrace{\theta_p}_{\text{slow, shared}}\,]$}
\end{center}
\vfill
\begin{center}\footnotesize
\textbf{Training} $=$ show the RNN \emph{thousands} of tasks; tune $\theta$ so that, after
reading each support set, it predicts the query well.
\end{center}
\end{frame}

% ---------------------------------------------------------------- The big idea: a learned learner
\begin{frame}{The big idea: learn a \emph{learner}, not a solution}
\begin{columns}[c]
\begin{column}{0.5\textwidth}
\centering
\resizebox{\linewidth}{!}{%
\begin{tikzpicture}[font=\footnotesize,
   box/.style={draw, rounded corners, minimum height=0.75cm, minimum width=1.6cm, align=center},
   ar/.style={-{Stealth[length=1.6mm]}, line width=0.9pt}]
  % ordinary
  \node[box, fill=boxtan!50] (d) {data};
  \node[box, fill=sysblue!45, right=24mm of d] (th) {solution $\theta$};
  \draw[ar] (d) -- node[above,font=\scriptsize]{learn} (th);
  \node[font=\scriptsize, left=2mm of d] {\textbf{ordinary}};
  % meta
  \node[box, fill=boxtan!50, below=1.6cm of d] (mt) {\emph{many} tasks};
  \node[box, fill=mlgreen!55, right=24mm of mt] (f) {learner $f_\theta$};
  \node[box, fill=sysblue!45, right=24mm of f] (sol) {solution};
  \draw[ar] (mt) -- node[above,font=\scriptsize]{meta-learn} (f);
  \draw[ar] (f) -- node[above,font=\scriptsize]{$+$ new task} (sol);
  \node[font=\scriptsize, left=2mm of mt] {\textbf{meta}};
\end{tikzpicture}}
\end{column}
\begin{column}{0.5\textwidth}
\footnotesize
Normally we learn a \textbf{solution}: data $\to$ weights that solve \emph{this} task ---
then throw them away for the next one.
\vspace{0.4em}

\empr{Meta-learning learns a \emph{learner}} $f_\theta$: a function that turns a new task's
experience \emph{into} a good solution. \textbf{That} is what we keep.
\vspace{0.5em}

Everything ahead just \emph{builds} $f_\theta$:
\begin{itemize}\itemsep1pt
   \item an RNN reading a support set (just now);
   \item an RNN reading experience in an MDP (next);
   \item a transformer reading a history (in-context RL, later).
\end{itemize}
\end{column}
\end{columns}
\vfill
\begin{center}\footnotesize
We don't learn the answer --- we learn \empy{how to produce answers}.
\end{center}
\end{frame}

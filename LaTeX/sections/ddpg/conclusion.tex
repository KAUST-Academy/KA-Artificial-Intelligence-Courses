\begin{frame}{Conclusion}
\begin{itemize}
    \item DDPG = DPG + DQN
    \item Big Idea is to bypass finding the local max of Q in DQN by jointly training a second neural network (actor) to predict the local max of Q.
    \vspace{0.3em}
    \item Tricks that made DDPG possible:
    \begin{itemize}
        \item Replay buffer, target networks (from DQN)
        \item Batch normalization, to allow transfer between different RL tasks with different state scales
        \item Directly add noise to policy output for exploration, due to continuous action domain
    \end{itemize}
    \item Despite these tricks, DDPG can still be sensitive to hyperparameters. TD3 and SAC offer better stability.
\end{itemize}
\end{frame}

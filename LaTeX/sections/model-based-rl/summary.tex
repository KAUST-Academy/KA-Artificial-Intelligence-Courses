% Slide 45
\begin{frame}{Summary}
\begin{itemize}
    \item Reinforcement Learning can be categorised into Model-Based and
          Model-Free.
    \item In Model-Based RL, we also learn the model of the world i.e, the
          state transition model and/or the reward model
    \item Model-Based RL can be employed with both value and/or policy
          based methods
    \item We can use the model to augment the real environment data
    \item Models can be immensely useful if easy to learn but sometimes they
          can be harder to learn than a policy
    \item Whether to use a model depends on how hard it is to learn
\end{itemize}
\end{frame}

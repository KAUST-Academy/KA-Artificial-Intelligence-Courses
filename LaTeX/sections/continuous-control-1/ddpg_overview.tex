\textbf{DDPG (Deep DPG) in one sentence:}
\begin{itemize}
    \item Extends DPG (Deterministic Policy Gradients) \rref{4} using deep learning,
    \item borrowing tricks from Deep Q-Learning (DQN) \rref{6}
    \item Contribution: model-free, off-policy, actor-critic approach that allows us to better learn deterministic policies on continuous action space
\end{itemize}
\end{frame}

\begin{frame}{DDPG}
\vspace{1em}
\textbf{DDPG (Deep DPG)} is a \emph{model-free, off-policy, actor-critic} algorithm that combines:
\begin{itemize}
    \item \textbf{DPG} (Deterministic Policy Gradients) \rref{4}: works over continuous action domain, not learning-based
    \item \textbf{DQN} (Deep Q-Learning) \rref{6}: learning-based, doesn't work over continuous action domain
\end{itemize}
\end{frame}

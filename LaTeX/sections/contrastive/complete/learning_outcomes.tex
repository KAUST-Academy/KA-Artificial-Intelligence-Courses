\begin{frame}[allowframebreaks]{Contrastive Learning: Learning Outcomes}
    By the end of this lecture, you will be able to:
    \begin{itemize}
        \setlength{\itemsep}{-0.1em}
        \item Trace how contrastive learning evolved from MoCo $\rightarrow$ SimCLR $\rightarrow$ BYOL $\rightarrow$ DINO $\rightarrow$ iBOT.
        \item Identify the design trade-offs: memory vs.\ compute, and negative sampling vs.\ representational collapse.
        \item Explain how batch size and temperature ($\tau$) shape the learned embeddings.
        \item Explain why the projection head is dropped when moving to downstream tasks.
        \item Analyze how BYOL avoids representational collapse without negative pairs.
        \item Illustrate why centering and sharpening the teacher's outputs prevent collapse in DINO.
    \end{itemize}
\end{frame}

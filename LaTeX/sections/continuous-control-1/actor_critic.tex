\begin{frame}{Why the Critic Is Now $Q_\phi(s,a)$ Instead of $V_\phi(s)$}
\vspace{0.6em}
The new actor update asks the critic: \emph{if I change the action, does the value go up?}
\vspace{0.4em}
\begin{itemize}
    \setlength{\itemsep}{0.5em}
    \item $V_\phi(s)$ has no action in it. There is nothing to differentiate. It can say ``this state is good'', but not ``turn the wheel left''.
    \item So Day 4's trick of learning only $V$ does not survive.
\end{itemize}
\pause
\vspace{0.9em}

\textbf{The good news: $Q$ costs us nothing extra.} Building a TD target normally means finding the best next action --- but the actor already hands us one:
\[
y \;=\; r + \gamma\, Q_{\phi^{-}}\!\big(s',\, \rbox{\mu_{\theta^{-}}(s')}\big)
\qquad\qquad
\mathcal{L}(\phi) = \mathbb{E}\big[(y - Q_\phi(s,a))^2\big]
\]
\vspace{0.2em}
\centering
Same squared TD error as Days 2 and 4. Only the way we pick the next action has changed.
\end{frame}

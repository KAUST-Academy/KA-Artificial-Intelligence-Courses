\section{Text-to-Image Generation Techniques}
\begin{frame}{}
    \LARGE Text-to-Image Generation Techniques
\end{frame}

\begin{frame}[allowframebreaks]{Text-to-Image Generation}
    \begin{itemize}
        \item Text-to-image generation involves creating images from textual descriptions.
        \item Requires alignment between vision and language features.
        \item Key techniques include:
        \begin{itemize}
            \item Diffusion models
            \item Generative adversarial networks (GANs)
            \item Variational autoencoders (VAEs)
        \end{itemize}
        \item Applications:
        \begin{itemize}
            \item Art and design
            \item Content creation
            \item Entertainment
            \item Virtual environments
            \item Accessibility
        \end{itemize}
    \end{itemize}
\framebreak
    \begin{itemize}
        \item Key challenges:
        \begin{itemize}
            \item Ensuring high fidelity to the text description.
            \item Maintaining diversity in generated images.
            \item Handling complex and abstract descriptions.
        \end{itemize}
    \end{itemize}

\subsection{GAN-based Approaches}
\begin{frame}[allowframebreaks]{GAN-based Approaches}
    \textbf{StackGAN} (Zhang et al., ICCV 2017): Generates images in two stages. Stage-I sketches the primitive shape and colours at $64\times64$; Stage-II re-reads the text and refines to $256\times256$.

\framebreak        
    \textbf{Stage-wise Generation:}
        \begin{itemize}
            \item Images are generated progressively, refining details at each stage.
        \end{itemize}
    \textbf{Limitations:}
        \begin{itemize}
            \item Training instability
            \item Mode collapse (lack of diversity in generated images)
        \end{itemize}
\end{frame}


\subsection{Diffusion-based Approaches}
\begin{frame}[allowframebreaks]{Diffusion-based Approaches}
    \begin{itemize}
        \item Diffusion models generate images by iteratively denoising random noise, conditioned on text prompts.
        \item Notable models:
        \begin{itemize}
            \item \textbf{DALL\textbullet E 2}
            \item \textbf{Imagen}
            \item \textbf{Stable Diffusion}
        \end{itemize}
        \item \textbf{Key idea:} Learn to reverse a gradual noising process, producing high-quality images from pure noise.
        \item \textbf{Advantages:}
        \begin{itemize}
            \item Superior image quality and diversity compared to GANs and VAEs
            \item Better alignment with textual descriptions
        \end{itemize}
    \end{itemize}
\framebreak
    \textbf{DALL\textbullet E 2 (unCLIP; Ramesh et al., 2022):} A \emph{prior} maps the CLIP text embedding to a CLIP \emph{image} embedding; a diffusion \emph{decoder} turns that into pixels. CLIP stays frozen throughout.

    \textbf{Diffusion Model Architecture:}
    \begin{itemize}
        \item \textbf{U-Net backbone:} The core neural network used for denoising, featuring an encoder-decoder structure with skip connections.
        \item \textbf{Text encoder:} Converts text prompts into embeddings. Common choices include T5 or CLIP Text Encoder.
        \item \textbf{Cross-attention:} Mechanism to inject text conditioning into the image generation process, allowing the model to align image features with textual information.
    \end{itemize}

\subsection{Measuring Text-to-Image Quality}
\begin{frame}{Measuring Text-to-Image Quality}
    Comparative claims about ``quality'' and ``prompt fidelity'' rest on two measurements:
    \begin{itemize}
        \item \textbf{FID (Fr\'echet Inception Distance):} Fits a Gaussian to the Inception features of a set of real images and another to those of a set of generated images, then measures the Fr\'echet distance between them. Lower is better. It penalises unrealistic samples \emph{and} lost variety, so it scores a set, never a single image (Heusel et al., NeurIPS 2017).
        \item \textbf{CLIPScore:} The cosine similarity between the CLIP embedding of the generated image and the CLIP embedding of the prompt. Higher means the image matches what was asked for (Hessel et al., EMNLP 2021).
    \end{itemize}
    \vspace{0.4em}
    The two pull against each other: turning the guidance scale up raises CLIPScore and, past a point, worsens FID. Papers therefore report a curve over guidance scales rather than one number.
\end{frame}

\subsection{Vision Transformers for Video}
\begin{frame}[allowframebreaks]{Vision Transformers for Video}
    \textbf{Vision Transformers (ViTs)} extend to video by treating a clip as a sequence of tokens, so self-attention can relate patches across both space and time.

    \begin{itemize}
        \item \textbf{Patch Embedding:} Each frame is divided into patches that are linearly embedded; ViViT's \emph{tubelet embedding} instead embeds spatio-temporal tubes spanning several frames, so each token already carries motion information.
        \item \textbf{Temporal Encoding:} Positional encodings are extended to the time dimension to preserve frame order.
        \item \textbf{Factorised Variants:} ViViT factorises the encoder into spatial then temporal stages, and pooling-based designs such as MViT progressively reduce the number of tokens, cutting the cost of full spatio-temporal attention.
    \end{itemize}

\section{Learning Outcomes}

\begin{frame}[allowframebreaks]{Learning Outcomes}
    By the end of this session, you will be able to:
    \begin{itemize}
        \setlength{\itemsep}{0.4em}
        \item Explain how a sound wave becomes a digital signal (sampling, quantization, bitrate).
        \item Explain how raw audio becomes features (MFCC, Mel/Log-Mel).
        \item Read \& reason about spectrograms (STFT, mel scale).
        \item Compare the main ASR architectures: CTC, attention-based encoder--decoder, transducers.
        \item Describe the Text-to-Speech (TTS) pipeline and where its difficulty lies.
        \item Connect features $\rightarrow$ ASR/NLU/TTS.
        \item Evaluate a system with the right metric (WER, CER, DER, MOS).
        \item Recognize the challenges and future directions in audio processing for NLP.
    \end{itemize}
\end{frame}

\begin{frame}[allowframebreaks]{\textcolor{green}{$\Rightarrow$} Learning Outcomes}
  By the end of this session, you should be able to:
  \begin{itemize}\itemsep0.24em
    \item[\textcolor{red}{$\blacktriangleright$}] State what a world model is, $s' \sim p(s' \mid s, a)$, and explain why prediction rather than search is what makes fast control possible.
    \item[\textcolor{red}{$\blacktriangleright$}] Describe the classic Vision--Memory--Controller architecture and how each module is trained.
    \item[\textcolor{red}{$\blacktriangleright$}] Contrast pixel-generative stacks with latent-predictive models, and say which one a given task calls for.
    \item[\textcolor{red}{$\blacktriangleright$}] Explain how an interactive video model can obtain an action space from video that carries no action labels.
    \item[\textcolor{red}{$\blacktriangleright$}] Identify the limitations that current systems share: rollout duration, closed action sets, and physical plausibility.
  \end{itemize}
\end{frame}

\section{Learning Outcomes}
\begin{frame}[allowframebreaks]{\textcolor{green}{$\Rightarrow$} Learning Outcomes}
    By the end of this session, you will be able to:
        \begin{itemize}
            \item See how deep CNNs have evolved over time.
            \item Get to know influential architectures: LeNet, AlexNet, VGG, InceptionNet, ResNet, EfficientNet, and MobileNet.
            \item Understand the key innovation behind each model (e.g., ReLU + dropout, small stacked filters, inception modules, skip connections, compound scaling, depthwise separable convolutions).
            \item Connect these architectures to the ImageNet benchmark that drove their development.
            \item Recall the common loss functions and optimizers used to train CNNs.
            \item Spot the limitations of CNNs and think about what’s next.
        \end{itemize}
\end{frame}

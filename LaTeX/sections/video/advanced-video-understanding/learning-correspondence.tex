\subsection{Learning correspondence}
\begin{frame}[allowframebreaks]{Learning correspondence}
    \textbf{Training data:} Unlabeled video \\[1em]

    \textbf{Pretext task:} Track a patch backward in time and then forward again; failing to return to the starting point is the training loss (the cycle-consistency of time). \\[1em]
    \textbf{Learning Correspondence:}

    \begin{itemize}
        \item Match patches across frames using the learned features
        \item Applications: tracking, video object segmentation, correspondence learning
    \end{itemize}

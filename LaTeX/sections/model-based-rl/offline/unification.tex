\begin{itemize}
    \item Learn a model from $\mathcal{D}$ $\to$ it is wrong off-support (the
          cliff!) $\to$ measure that with ensemble disagreement $\to$ build a
          \emph{pessimistic MDP} $\to$ run MBPO inside it
    \item \textbf{MOReL}, \textbf{MOPO}, \textbf{COMBO} are all instances of
          \emph{one} idea: learn a model from the batch, then \emph{subtract a
          penalty wherever the model is uncertain} (e.g.\ reward
          $\hat r - \lambda\, u(s,a)$). This is pessimism, now about the \emph{model}
\end{itemize}
\end{frame}

\begin{frame}{One Story, Two Signs}
\begin{itemize}
    \item Exploration (Day 7) and offline RL (today) are the \textbf{same OOD
          problem, in reverse}
    \item Online: uncertainty is an opportunity, so add the bonus and go look
    \item Offline: uncertainty is a hazard, so subtract the bonus and stay home
\end{itemize}
\vspace{0.8em}
\begin{center}
\textcolor{red}{Optimism for exploration, pessimism for offline data:
 the sign of the uncertainty bonus is the whole story.}
\end{center}
\end{frame}

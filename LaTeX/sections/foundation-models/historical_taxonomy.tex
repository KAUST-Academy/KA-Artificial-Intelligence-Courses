\begin{frame}{Two major classes of vision foundation models}
  \begin{columns}[T,onlytextwidth]
    \column{0.48\textwidth}
      {\color{KAUSTblue}\textbf{Representation Learners}} \\[0.5em]
      {\color{KAUSTred}Train on huge amounts of data} \\[0.2em]
      \textbf{Objective:} learn powerful generalist feature extractors that can be used for downstream computer vision tasks.
      \begin{itemize}\itemsep0.32em
        \item Vision Only (e.g.\ DINOv2)
        \item Vision-Language (e.g.\ CLIP)
      \end{itemize}
    \column{0.04\textwidth}
    \column{0.48\textwidth}
      {\color{KAUSTcyan}\textbf{Generative Models}} \\[0.5em]
      {\color{KAUSTred}Train on huge amounts of data} \\[0.2em]
      \textbf{Objective:} learn to generate images and/or text.
      \begin{itemize}\itemsep0.32em
        \item Text $\rightarrow$ Image (e.g.\ Stable Diffusion, DALL-E)
        \item Text, Image $\rightarrow$ Text (e.g.\ Flamingo, GPT-4V)
      \end{itemize}
  \end{columns}
\end{frame}

% --- Generative class in brief ---
\begin{frame}{The Generative Class in Brief}
  \begin{itemize}\itemsep0.3em
    \item \textbf{Text-to-image diffusion} (Stable Diffusion, DALL-E): start from random noise and iteratively \textbf{denoise} it, conditioned on a text prompt. The denoiser is trained on billions of captioned images; latent diffusion (Rombach et al., 2022) runs the process in a compressed latent space to cut cost.
    \item \textbf{Vision-language generative models} (Flamingo, GPT-4V, LLaVA): a vision encoder feeds visual tokens into an \textbf{LLM} through a small projector, the same pattern as the V-JEPA 2 language alignment covered earlier. The LLM then generates text about the image.
    \item Text conditioning in both cases relies on strong text encoders; Stable Diffusion uses \textbf{CLIP's} text encoder, which we cover next.
    \item This lecture focuses on the \textbf{representation-learning} class; generative modeling is covered in its own lectures elsewhere in the course.
  \end{itemize}
\end{frame}

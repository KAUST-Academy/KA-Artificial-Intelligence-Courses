\begin{frame}{Overlapping Boxes: Non-Max Suppression (NMS)}
\begin{columns}
    \begin{column}{0.5\textwidth}
    \begin{itemize}
        \item<1-> \textbf{Problem:} Object detectors often output many overlapping detections
        \item<2-> \textbf{Solution:} Post-process raw detections using Non-Max Suppression (NMS)
        \onslide<3->{
        \begin{enumerate}
            \item Select next highest-scoring box
            \item Eliminate lower-scoring boxes with IoU $>$ threshold (e.g. 0.7)
            \item If any boxes remain, GOTO 1
        \end{enumerate}
        }
        \item<5-> \textcolor{red}{\textbf{Problem:} NMS may eliminate ``good'' boxes when objects are highly overlapping… no good solution =( }
    \end{itemize}
    \end{column}

\begin{frame}{Two Stages or One?}
    \begin{itemize}
        \item \textbf{Two-stage} (the R-CNN family): stage one proposes a few thousand candidate regions, stage two runs a classifier and a box regressor \emph{once per region}. Every proposal gets a second look, and the cost of inference grows with the number of proposals.
        \item \textbf{Single shot}: one network predicts a class score and a box offset for every location in a dense, fixed grid of cells or anchors, in a single forward pass. There is no proposal stage, so the runtime does not depend on how many objects are in the image.
        \item The two families that established this design are \textbf{SSD} (Single Shot MultiBox Detector), which predicts from several feature maps at different scales, and \textbf{YOLO}, which we turn to next.
        \item \textbf{The trade-off:} single-shot detectors are far faster, but they must score a huge number of locations of which nearly all are background, and they historically lag two-stage detectors in accuracy, particularly on small objects.
    \end{itemize}
\end{frame}

\begin{frame}{A First Algorithm: Planning}
\begin{itemize}
    \item We take the first option \textbf{(planning)}: use the model to choose
          good actions directly, with no separate policy yet. The simplest version:
    \begin{enumerate}
        \item Run some policy (e.g.\ random policy) to collect data
              $D = \{(s, a, r, s')_i\}$
        \item Learn the model $f_\phi(s, a)$ (weights $\phi$) to minimize
              $\sum_i \lVert f_\phi(s_i, a_i) - s'_i \rVert$
        \item Iteratively sample action sequences, run through model $f_\phi(s, a)$ to
              choose actions
    \end{enumerate}
\end{itemize}
\end{frame}

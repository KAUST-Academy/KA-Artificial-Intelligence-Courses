\begin{frame}{Future Directions}
    \textbf{Open problems the three papers leave behind:}
    \begin{itemize}
        \item Scaling laws derived for byte-level models, instead of borrowing the compute-optimal schedule of subword transformers.
        \item Patch boundaries learned end to end, rather than handed down by a separate entropy model.
        \item Byte-ifying existing tokenizer-based checkpoints, so a byte-level model need not be trained from scratch.
        \item Serving machinery for bidirectional models: caching without a prefix, and generation lengths the model chooses itself.
        \item RL-based alignment for diffusion language models, which so far stop at supervised fine-tuning.
    \end{itemize}
\end{frame}

\begin{frame}{Key Takeaways}
    \begin{itemize}
        \item \textbf{LLaMA 3}: Open weights at frontier quality widen access to research and deployment.
        \item \textbf{BLT}: Learned byte patches remove the tokenizer, trading fixed vocabulary for dynamic, entropy-driven compute allocation.
        \item \textbf{LLDMs}: Diffusion-based generation is an alternative to left-to-right decoding, enabling parallel refinement of whole sequences.
        \item Each paradigm removes a different fixed assumption of the standard transformer recipe.
    \end{itemize}
\end{frame}

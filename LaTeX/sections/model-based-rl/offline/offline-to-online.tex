\begin{itemize}
    \item In practice: \textbf{pretrain offline} (data is free) $\to$
          \textbf{fine-tune online} (interaction is scarce and expensive)
    \item Naive fine-tuning dips first: the pessimistic values get violently
          re-calibrated before they improve
    \item Fixes keep the offline ballast while admitting new data: AWAC, Cal-QL, RLPD
    \item You already know this recipe's most famous instance: \emph{pretrain on
          logged human data, then fine-tune with RL}, the LLM pipeline (Day 9!)
\end{itemize}

\subsection{InceptionNet}
\begin{frame}{}
    \LARGE CNN Architectures: \textbf{InceptionNet}
\end{frame}

\begin{frame}[allowframebreaks]{InceptionNet}
    \begin{itemize}
        \item InceptionNet goes \textbf{deeper} with 22 layers.
        \item It is much more \textbf{efficient}: about 6.8 million parameters, far fewer than AlexNet's 60M.
        \item Uses a special building block called the \textbf{Inception module}.
        \item Adds \textbf{1x1 convolutions} (bottleneck layers) to make the network faster and smarter.
        \item Won the ILSVRC 2014 classification task with 6.7\% top-5 error.
    \end{itemize}

    \begin{itemize}
        \item \textbf{Inception module:} Runs $1\times1$, $3\times3$ and $5\times5$ convolutions and a $3\times3$ max-pooling branch in parallel, then concatenates their outputs along the channel axis.
        \item The naive version (a) is expensive, so GoogLeNet uses (b): a $1\times1$ convolution shrinks the channel count before each $3\times3$ and $5\times5$ convolution, and after the pooling branch.
    \end{itemize}

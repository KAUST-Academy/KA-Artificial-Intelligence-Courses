\begin{frame}{Learning Outcomes}
    By the end of this session, you will be able to:

    \vspace{0.5em}
    \begin{enumerate}
        \item Describe the ML lifecycle from experiment to operated system, and name the failure mode that lives at each stage.

        \item Make a training run reproducible: seeds, deterministic operations, environment pinning, and data/config versioning.

        \item Track experiments with MLflow or Weights \& Biases, and run a systematic hyperparameter search with Optuna.

        \item Package a model and serve it behind an API, and choose between batch and online serving.

        \item Design basic production monitoring: data drift, concept drift, performance alerts, and retraining triggers.
    \end{enumerate}
\end{frame}

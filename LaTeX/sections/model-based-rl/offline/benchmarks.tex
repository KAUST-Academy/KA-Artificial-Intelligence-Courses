\begin{itemize}
    \item Offline RL is measured on shared \textbf{benchmark suites} of fixed
          datasets: the standard one is \textbf{D4RL} (``Datasets for Deep
          Data-Driven RL'')
    \item Its tasks stress different skills: e.g.\ a maze-navigation set built
          to \emph{require stitching}, or a dexterous-hand set of \emph{human
          demonstrations}
    \item Each task comes at several \emph{data qualities} (random / medium /
          expert mixtures), and method rankings flip between them
    \item Scores are normalized ($0 =$ random, $100 =$ expert); on expert data
          plain BC is hard to beat, so \textbf{always run it as the baseline}
\end{itemize}

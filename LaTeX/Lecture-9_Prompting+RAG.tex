\begin{frame}[t]{Why Prompting and RAG?}
  \begin{itemize}
    \item LLMs (Large Language Models) are powerful but have limitations:
    \begin{itemize}
      \item[\textcolor{red}{$\blacktriangleright$}] \textbf{Static knowledge} (limited to training data)
      \item[\textcolor{red}{$\blacktriangleright$}] \textbf{Prone to hallucinations}
      \item[\textcolor{red}{$\blacktriangleright$}] \textbf{Require careful input phrasing}
    \end{itemize}
    \vspace{1em}
    \item Prompting helps guide LLM behavior.
    \vspace{1em}
    \item RAG (Retrieval-Augmented Generation) addresses knowledge limitations by combining LLMs with external retrieval.
  \end{itemize}
\end{frame}

\begin{frame}{Real-World Motivation}
  Chatbots, search engines, and coding assistants require:
  \begin{itemize}
    \item[\textcolor{red}{$\blacktriangleright$}] Accurate, real-time information
    \item[\textcolor{red}{$\blacktriangleright$}] Robust language understanding
  \end{itemize}

  \vspace{1em}
  Prompting combined with RAG enables systems that are:
  \begin{itemize}
    \item[\textcolor{red}{$\blacktriangleright$}] Customizable
    \item[\textcolor{red}{$\blacktriangleright$}] Scalable
    \item[\textcolor{red}{$\blacktriangleright$}] Easily updatable
  \end{itemize}
\end{frame}

\begin{frame}{What are prompts?}
  \begin{itemize}
    \item[\textcolor{red}{$\blacktriangleright$}] \textbf{Prompts} involve instructions and context passed to a language model to achieve a desired task.
    \vspace{0.5em}
    \item[\textcolor{red}{$\blacktriangleright$}] \textbf{Prompt engineering} is the practice of developing and optimizing prompts to efficiently use language models (LMs) for a variety of applications.
    \vspace{0.5em}
    \item[\textcolor{red}{$\blacktriangleright$}] Prompt engineering is a useful skill for AI engineers and researchers to improve and efficiently use language models.
  \end{itemize}
\end{frame}

\begin{frame}{Parameters of Decoding}
  \begin{itemize}
    \item[\textcolor{red}{$\blacktriangleright$}] Greedy/Beam Search generates less surprising/boring responses. Not desirable for open-ended tasks like dialog and story-telling.
    \item[\textcolor{red}{$\blacktriangleright$}] Instead, sampling can be used.
  \end{itemize}
  
  \begin{center}
    \includegraphics[width=0.85\linewidth]{assets/Lecture-9_Prompting+RAG/slide_parameters_of_decoding.png}
  \end{center}
  
  \begin{itemize}
    \item[\textcolor{red}{$\blacktriangleright$}] \textbf{Temperature}
      \begin{itemize}
        \item controls sharpness of the next-token distribution
        \item value between 0 to 1
        \item lower temperature $\rightarrow$ sharper distribution $\rightarrow$ repetitive generations
      \end{itemize}
    \item[\textcolor{red}{$\blacktriangleright$}] \textbf{Top $p$}
      \begin{itemize}
        \item value between 0 to 1
        \item select smallest set of tokens whose total likelihood exceeds $p$. Redistribute the probabilities
        \item smaller $p$ leads to repetitive generations
      \end{itemize}
  \end{itemize}
  {\scriptsize
    \textbf{Source:} \url{https://huggingface.co/blog/how-to-generate}
  }
\end{frame}

\begin{frame}{Settings to Keep in Mind}
  \begin{itemize}
    \item When prompting a language model, you should keep in mind a few settings.
    \vspace{0.5em}
    \item You can get very different results with prompts when using different settings.
    \vspace{0.5em}
    \item One important setting is controlling how \textbf{deterministic} the model is when generating completions for prompts:
      \begin{itemize}
        \item \textbf{Temperature} and \textbf{top\_p} are two important parameters to keep in mind.
        \item Generally, keep these low if you are looking for exact answers.
        \item \dots keep them high if you are looking for more diverse responses.
      \end{itemize}
  \end{itemize}
\end{frame}

\begin{frame}{Self-Consistency}
  \begin{itemize}
    \item \textbf{Self-Consistency} aims to improve on the naive greedy decoding used in chain-of-thought prompting
    \item The idea is to sample multiple, diverse \textbf{reasoning paths} through few-shot CoT, and use the generations to select the most \textbf{consistent answer}.
    \item This helps to boost the performance of CoT prompting on tasks involving arithmetic and \textbf{commonsense reasoning}
  \end{itemize}

\begin{frame}{ReAct}
  \begin{itemize}
    \item ReAct is a framework where LLMs are used to generate both reasoning traces and task-specific actions in an interleaved manner
    \begin{itemize}
      \item \textbf{Generating reasoning traces} allow the model to induce, track, and update action plans, and even handle exceptions
      \item \textbf{The action step} allows to interface with and gather information from external sources such as knowledge bases or environments.
    \end{itemize}
    \item ReAct allows LLMs to interact with external tools to retrieve additional information that leads to more reliable and factual responses
  \end{itemize}

\begin{frame}{Jailbreaking}
  \textbf{Jailbreaking}
  
  \vspace{0.8em}
  \begin{itemize}
    \item Jailbreaking is another form of prompt injection where the goal is to bypass safety and moderation features.
    \item LLMs provided via APIs might be coupled with safety features or content moderation which can be bypassed with harmful prompts/attacks.
    \item This might sound like a difficult task but it's not because the model is usually served static and might have these vulnerabilities due to many factors such as the data it was trained on, etc.
  \end{itemize}
\end{frame}

\begin{frame}{Working with extremely low resource languages\\(Multilingual)}

  \small
  It is well known that only a very limited proportion of the languages spoken in the world is covered by technology or by scientific knowledge. For technology, only normative productions of very few languages in very few situations are mastered. The technological divide is wide considering the languages spoken: we have a minimally adequate quantity of data for less than 1\% of the world's 7,000 languages. Most of the world's everyday life speech stems from languages which are essentially unwritten and we include in these languages; ethnolects as well as sociolects such as many regional varieties of Arabic, Shanghainese, slang \ldots\ There are thousands of endangered languages for which hardly any documentation exists and time is running out before they disappear: some linguists estimate that half of the presently living languages will become extinct in the course of this century\footnote{Adda et al 2016}.

  \vspace{1em}
  \begin{itemize}
    \setlength\itemsep{0.6em}
    \item \textcolor{red!70!black}{$\triangleright$} Most languages do not have machine-readable, written text
    \item \textcolor{red!70!black}{$\triangleright$} Many such languages may become extinct
    \item \textcolor{red!70!black}{$\triangleright$} Little for-profit motive to serve these languages -- vicious feedback loop
  \end{itemize}

  \vspace{0.5em}
  \hfill \scriptsize{[Adda et al 2016]}
\end{frame}

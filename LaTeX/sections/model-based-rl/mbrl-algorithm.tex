\begin{frame}{Model-Based RL}
\begin{itemize}
    \item So, now we have the following algorithm
    \begin{enumerate}
        \item Run some policy (e.g.\ random policy) to collect data
              $D = \{(s, a, s')_i\}$
        \item Learn model $f_\phi(s, a)$ to minimize $\sum_i \lVert f_\phi(s_i, a_i) - s'_i \rVert$
        \item Iteratively sample action sequences, run through model $f_\phi(s, a)$ to
              choose actions
    \end{enumerate}
\end{itemize}
\end{frame}

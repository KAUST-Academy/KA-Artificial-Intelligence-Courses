\section{Motivation}
\begin{frame}{Motivation}
    \begin{itemize}
        \item \textbf{Why study Mixture of Experts?}
        \begin{itemize}
            \item Scaling dense LLMs is costly: every parameter participates in every forward pass, so capacity and compute grow together.
            \item \textbf{MoE models} break that link: massive total capacity with far lower computation per token, because only a few experts activate per input.
            \item Many frontier systems are MoE models (e.g.\ DeepSeek-V3/R1 with 671B total but 37B active parameters; Mixtral; Switch Transformer).
        \end{itemize}
        \item \textbf{Example:}
        \begin{itemize}
            \item \textit{A dense 671B model would be prohibitively expensive to serve; DeepSeek-R1 routes each token through a small subset of experts, giving 671B-scale capacity at roughly the inference cost of a 37B model.}
        \end{itemize}
        \item Large Reasoning Models build directly on these architectures: several leading reasoning systems are trained and served as MoE models.
    \end{itemize}
\end{frame}

\subsection{Leading Large Reasoning Models}
\begin{frame}[allowframebreaks]{Leading Large Reasoning Models}
    \large Following are some of the leading Large Reasoning Models (LRMs) as of 2024/2025:
    \vspace{0.5em}
    \begin{itemize}
        \item \textbf{OpenAI o1/o3}
        \begin{itemize}
            \item \textbf{Architecture:} Undisclosed; trained with reinforcement learning to reason before answering.
            \item \textbf{Training Data Transparency:} Proprietary, limited details.
            \item \textbf{Strengths:} High-quality reasoning, STEM, coding.
            \item \textbf{Reasoning Approach:} Hidden chain of thought, with the effort budget selectable as low, medium, or high.
            \item \textbf{Efficiency:} 200K context window, 100K maximum output tokens.
            \item \textbf{Best Use Case:} General AI, STEM research, API function calling.
        \end{itemize}
    \framebreak
        \item \textbf{DeepSeek R1}
        \begin{itemize}
            \item \textbf{Architecture:} Mixture of Experts (MoE, 671B total, 37B active).
            \item \textbf{Training Data Transparency:} Open weights (MIT licence); base model pretrained on 14.8T tokens and the RL recipe described in the paper.
            \item \textbf{Strengths:} Math, coding, and STEM reasoning at open-weight cost.
            \item \textbf{Reasoning Approach:} Large-scale RL on problems whose answers can be checked automatically, producing long explicit chains of thought.
            \item \textbf{Efficiency:} Only 37B of 671B parameters are active per token, so each token costs a fraction of a dense model of the same size.
            \item \textbf{Best Use Case:} Self-hosted reasoning assistant, coding and debugging.
        \end{itemize}
    \framebreak
        \item \textbf{Gemini 2.0 (Flash Thinking)}
        \begin{itemize}
            \item \textbf{Architecture:} Multimodal Transformer (Text+Image+Speech).
            \item \textbf{Training Data Transparency:} Proprietary, multimodal (text, images, APIs).
            \item \textbf{Strengths:} Multimodal (images, text, speech), deep reasoning.
            \item \textbf{Reasoning Approach:} Flash Thinking mode (transparent thought process).
            \item \textbf{Efficiency:} 1M token context (experimental), optimized for speed.
            \item \textbf{Best Use Case:} AI assistant (multimodal, research, planning).
        \end{itemize}
    \framebreak
        \item \textbf{Claude 3.7 Sonnet}
        \begin{itemize}
            \item \textbf{Architecture:} Undisclosed; a single model that answers either immediately or after extended thinking.
            \item \textbf{Training Data Transparency:} Proprietary; evaluations documented in a published system card.
            \item \textbf{Strengths:} Coding, agentic tasks, long-form dialogue.
            \item \textbf{Reasoning Approach:} Extended thinking, shown to the user rather than hidden.
            \item \textbf{Efficiency:} 200K context; thinking can be switched off, and its token budget set per API call.
            \item \textbf{Best Use Case:} One deployment covering both quick replies and hard problems.
        \end{itemize}
    \framebreak
        \item \textbf{Magistral (Mistral)}
        \begin{itemize}
            \item \textbf{Architecture:} Dense Transformer; Magistral Small at 24B, Magistral Medium for enterprise use.
            \item \textbf{Training Data Transparency:} Magistral Small released open-weight under Apache 2.0, with the RL recipe published.
            \item \textbf{Strengths:} Reasoning traces that stay in the user's own language across scripts and alphabets.
            \item \textbf{Reasoning Approach:} RL-trained chains of thought, kept legible for review.
            \item \textbf{Efficiency:} 24B open-weight variant, self-hostable.
            \item \textbf{Best Use Case:} Regulated or multilingual settings where the trace must be auditable.
        \end{itemize}
    \framebreak
        \item \textbf{QwQ (Alibaba)}
        \begin{itemize}
            \item \textbf{Architecture:} Dense Transformer (32B), RL-trained for reasoning.
            \item \textbf{Training Data Transparency:} Open weights under Apache 2.0; training corpus undisclosed.
            \item \textbf{Strengths:} Math, logical puzzles, chain-of-thought self-verification.
            \item \textbf{Reasoning Approach:} Outcome-reward RL scaled up from a cold-start checkpoint, plus self-reflection.
            \item \textbf{Efficiency:} 32B parameters, yet comparable to DeepSeek-R1 on several reasoning benchmarks.
            \item \textbf{Best Use Case:} Mathematical proofs, advanced reasoning on modest hardware.
        \end{itemize}
    \end{itemize}
\end{frame}

\begin{frame}{Introduction to Attention}
    \begin{itemize}
        \item \textbf{Problem:} the encoder squeezes the whole input into one final hidden state, and the decoder never sees anything else.
        \item \textbf{Key idea:} let the decoder look back at all of the encoder's hidden states, and decide at each step which ones matter.
    \end{itemize}
    \vspace{0.6em}
    Given encoder hidden states $h_1, \dots, h_N$ and decoder state $s_{t-1}$:
    \begin{align*}
        e_{t,i} = f_{\text{att}}(s_{t-1}, h_i), \qquad
        a_{t,i} = \frac{\exp(e_{t,i})}{\sum_{j=1}^{N} \exp(e_{t,j})}, \qquad
        c_t = \sum_{i=1}^{N} a_{t,i}\, h_i
    \end{align*}
    \begin{itemize}
        \item $e_{t,i}$ scores how well input $i$ matches what the decoder needs now; $f_{\text{att}}$ is a small trained network.
        \item The weights $a_{t,i}$ are positive and sum to 1, so the context vector $c_t$ is a weighted average of encoder states.
        \item Introduced for machine translation by Bahdanau et al.\ (2015).
    \end{itemize}
\end{frame}

        \item Use a different context vector at each timestep of the decoder.
        \item The input sequence is not bottlenecked through a single vector.
        \item At each timestep of the decoder, the context vector ``looks at'' different parts of the input sequence.
    \end{itemize}
